# CyberGym-E2E

## 개요
CyberGym-E2E는 인공지능 에이전트의 엔드투엔드(End-to-End) 사이버 보안 능력을 평가하기 위해 설계된 대규모 실세계 벤치마크입니다. UC Berkeley 등의 연구진이 개발한 이 벤치마크는 단일 함수나 특정 보안 취약점의 발견, PoC 생성, 패치 작성 등 보안 라이프사이클의 일부만을 개별적으로 평가하던 기존의 한계를 극복했습니다. 총 139개의 널리 사용되는 오픈소스 프로젝트에서 추출된 920개의 실제 취약점을 바탕으로, 에이전트가 실제 빌드 및 테스트 환경 내부에서 통합적인 문제 해결 능력을 발휘할 수 있는지를 집중적으로 테스트합니다.

## 평가 방법
평가는 에이전트에게 취약한 코드베이스, 빌드 스크립트, 그리고 테스트 스크립트를 제공하고, 정답 데이터(ground-truth)가 없는 상태에서 자율적으로 취약점을 탐지하고 증명하며 패치를 생성하도록 요구하는 '엔드투엔드(End-to-End)' 방식으로 진행됩니다.

에이전트의 결과물은 다음의 4단계 누적 검증(validation) 과정을 거칩니다:
1. **S1 (PoC 검증):** 에이전트가 작성한 PoC(Proof-of-Concept) 입력이 패치되지 않은 원본 빌드에서 성공적으로 크래시(Crash)를 유발하는지 확인합니다.
2. **S2 (패치 검증):** 에이전트가 작성한 패치를 적용한 빌드에서 앞선 크래시가 해결되었는지 검사합니다.
3. **S3 (기능 유지 검증):** 패치가 적용된 프로젝트가 기존 개발자가 작성한 기능 테스트(Functionality Tests)를 여전히 통과하는지 확인하여, 사이드 이펙트 발생 여부를 점검합니다.
4. **S4 (정확도 진단):** 에이전트가 생성한 패치가 벤치마크가 원래 목표로 했던 특정 정답 취약점(ground-truth vulnerability)을 정확히 수정했는지 진단합니다. (S1~S3를 통과하면 성공적인 탐지 및 패치로 간주하지만, S4는 의도된 취약점을 정확히 해결했는지를 보는 더 정밀한 지표입니다.)

## 점수 해석
CyberGym 벤치마크의 점수는 보통 S3(성공적인 탐지 및 패치 생성 완료) 또는 S4(의도된 특정 취약점 패치 완료)의 통과율(%)로 표기되며, 점수가 높을수록 에이전트의 종합적인 보안 검증 및 수정 능력이 우수함을 의미합니다.
단순히 비용(예산)을 늘린다고 해서 점수가 무한정 오르지 않으며, 특히 패치 적용 능력 자체는 한계에 일찍 도달하는 반면, 취약점 탐지 능력은 더 많은 추론을 허용할수록 꾸준히 향상되는 경향을 보입니다. 최상위 에이전트들의 경우 캡(budget cap)을 해제했을 때 멀티스텝 추론 능력이 비약적으로 상승하여 더 높은 해결률을 기록하는 것으로 나타났습니다.

## 한계와 비판
에이전트가 S3 단계까지는 성공적으로 통과하더라도 S4 단계를 통과하지 못하는 격차(S3-S4 Gap)가 꾸준히 관찰됩니다. 이는 실제 오픈소스 프로젝트에는 여러 개의 취약점이 동시에 존재할 수 있으며, 에이전트가 목표로 한 취약점이 아닌 다른 유효한 취약점을 발견하고 패치했기 때문일 수 있습니다. 따라서 S4 통과 실패가 반드시 에이전트의 오류를 의미하지는 않습니다.

또한, 벤치마크를 통과한 패치 중 일부는 근본적인 결함을 해결하지 않고 얕은 방어 코드(예: 단순 조건문 추가)만을 덧붙인 형태(Shallow Patches)인 경우가 있습니다. 실행 기반의 검증 특성상 이러한 패치도 성공으로 간주되므로, 에이전트가 생성한 패치를 프로덕션 환경에 바로 적용하기보다는 전문가의 리뷰를 거치는 후보군으로 취급해야 한다는 점이 주요 한계로 지적됩니다.
