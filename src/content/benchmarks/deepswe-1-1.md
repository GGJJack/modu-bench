# DeepSWE 1.1

## 개요
DeepSWE 1.1은 기존 DeepSWE 1.0의 뒤를 잇는 고도화된 소프트웨어 엔지니어링 벤치마크입니다. 개발자나 코딩 에이전트가 단편적인 코드 조각을 작성하는 것을 넘어서, 실제 소프트웨어 개발 환경에서 요구되는 '긴 호흡(long-horizon)'의 복잡한 문제를 해결할 수 있는지를 평가하는 데 중점을 둡니다.

## 평가 방법
오픈소스 생태계에서 활동 중인 실제 프로젝트의 환경과 요구사항을 기반으로 과제를 구성합니다. 모델은 주어진 이슈나 요구사항을 분석하고, 여러 파일에 걸쳐 코드를 수정하거나 새로운 기능을 구현해야 합니다. 특히 기존 1.0 버전에 이어, 최신 최상위 모델들 사이에서도 의미 있는 성능 차이를 변별해낼 수 있도록 난이도와 평가 정밀도를 조정했습니다.

## 의의 및 한계
단일 파일에서의 간단한 버그 수정이나 코드 완성만을 평가하는 벤치마크들과 비교해, DeepSWE 1.1은 모델이 소프트웨어 전체의 구조를 이해하고 논리적으로 코드를 작성하는 능력을 더 잘 보여줍니다. 그러나 이러한 평가는 환경 설정, 평가 스크립트의 강건성 등에 영향을 많이 받기 때문에, 평가 환경을 구축하고 일관된 점수를 도출하는 과정 자체가 매우 까다롭다는 한계가 있습니다.
