# FrontierCode (Main)

## 개요
FrontierCode (Main)은 프론티어 코딩 에이전트 성능을 평가하는 벤치마크입니다. AI 에이전트의 코드 변경 사항이 실제 소프트웨어 프로젝트에 머지(Merge)될 수 있는지를 측정합니다.

## 평가 방법
에이전트가 코드를 변경하는 작업을 수행하며, 이 변경 사항이 머지될 수 있는지의 성공률(%)을 평가합니다.

## 점수 해석
성공률(%)로 표기되며, 높을수록 에이전트의 실질적인 코딩 역량이 우수함을 의미합니다.
