# Llama 3.2 1B 소개

## 개요
Llama 3.2 1B는 Meta가 2024년 9월 25일 개발자 컨퍼런스인 Meta Connect 2024에서 공개한 초경량 오픈 가중치(Open weights) 언어 모델입니다. 이 모델은 10억 개의 파라미터 크기를 바탕으로 모바일 기기, 웨어러블 단말, 엣지 컴퓨터 등 리소스가 지극히 제한된 온디바이스(On-device) 환경에서 최상의 추론 효율성을 제공하도록 특화되었습니다. 대규모 인프라나 인터넷 연결 없이 단말 단에서 지연 시간(Latency)을 최소화하면서 즉각적인 텍스트 처리를 수행할 수 있는 것이 주요 포지셔닝입니다.

## 기술 특징
Llama 3.2 1B는 소형 체급임에도 불구하고 대형 모델의 정수를 이식하여 **128,000 토큰(128K)의 방대한 컨텍스트 윈도우**를 기본적으로 지원합니다. 덕분에 책 한 권 분량이나 긴 코드베이스 등을 입력받아 핵심을 관통하는 추론이나 요약 작업을 로컬 디바이스에서 독자적으로 해결합니다. 또한, 연산 복잡도를 줄이기 위해 검증된 **GQA(Grouped-Query Attention)** 기법을 활용하여 VRAM 점유율을 획기적으로 낮추었고, 인공지능이 외부 API나 가상의 실행 도구를 호출하여 문제를 해결하는 **고급 도구 사용(Tool Use)** 역량이 소형화된 인스트럭션 튜닝을 통해 내장되었습니다.

## 사용 사례
이 모델은 극도로 빠른 응답 속도가 생명인 인터랙티브 애플리케이션 및 하드웨어 상주형 소프트웨어에서 완벽한 가치를 지닙니다. 예컨대, 사용자 스마트폰 내부에서 실시간으로 작동하는 온디바이스 음성 비서 제어, 문자 메시지 및 이메일의 로컬 오타 수정 및 실시간 요약, 그리고 오프라인 지식 기반 질의응답(RAG)의 로컬 추론 엔진으로 애용됩니다. 더불어, 고가의 대형 모델을 상시 가동하기 힘든 소규모 자동화 시나리오에서 API 호출 이전에 사용자 입력을 전처리하거나 유해 정보를 필터링하는 경량 프런트엔드 에이전트 레이어로도 다방면에서 기용되고 있습니다.

## 한계
1B 크기의 구조적 용량 한계로 인해, 극도로 난해한 전문 지식 분야(예: 고급 수리 물리 분석, 미수정 전문 사법 서류 검토)나 여러 단계의 심층 추론이 필요한 영역에서는 상대적으로 환각(Hallucination) 비중이 높게 관찰될 수 있습니다. 또한, 다국어 지식 및 정교한 문화적 문맥 조율 수준이 Llama 3.1 70B/405B와 같은 초대형 라인업에 비해서는 단순한 구문 형태로 제한되는 경향이 있습니다. 텍스트 지향 지능에 고도로 집중되어 있어 단독으로 복잡한 이미지 픽셀 분석이나 실시간 오디오 파형 직접 생성 등 멀티모달 작업을 연속적으로 완수할 수는 없으며, 별도의 멀티모달 컴포넌트와의 추가적인 결합이 수반되어야 합니다.
