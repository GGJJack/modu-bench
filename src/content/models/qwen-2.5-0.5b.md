# Qwen2.5 0.5B 소개

## 개요
Qwen2.5 0.5B는 Alibaba Cloud가 2024년 9월 19일에 발표한 Qwen2.5 대형 언어 모델 패밀리의 극소형 초경량(0.5B) 언어 모델입니다. 파라미터 수가 5억 개 수준에 불과함에도 불구하고, 18조(18T) 토큰에 달하는 방대한 고품질 데이터셋을 사전 학습하여 동일 체급의 경량 LLM(SLM) 대비 압도적인 한국어 및 다국어 언어 이해력과 기초 추론 능력을 선사합니다. 로컬 단말기, 임베디드 디바이스, 라즈베리 파이 등 메모리와 계산 자원이 엄격하게 제약된 경량 환경에서도 높은 효율성으로 고속 서빙이 가능하도록 특화 설계되었습니다.

## 기술 특징
Qwen2.5 0.5B는 전작인 Qwen2 0.5B에 비해 코딩 지식, 수리 추론, 구조화된 출력(JSON/Table) 생성 성능이 대폭 향상되었습니다. 모델 크기는 작지만 **최대 32,768(32K) 토큰의 컨텍스트 윈도우**를 완벽히 지원하며, 최대 8K 토큰의 답변 생성을 처리할 수 있어 소형 모델의 한계로 지목되던 긴 문맥 처리 문제를 상당 부분 극복하였습니다. 더불어, 한국어를 비롯해 29개 이상의 주요 언어에 대한 우수한 고속 토크나이저 효율성을 제공하며, Apache-2.0 라이선스가 적용되어 상용 디바이스 탑재 시 법적 유연성을 보장합니다.

## 사용 사례
모바일 앱, IoT 센서 단말, 웹 브라우저 내부(WebGPU/Wasm)에서 네트워크 연결 없이 실시간으로 동작하는 온디바이스 AI 인퍼런스 엔진으로 널리 활용됩니다. 또한 소형 에이전트의 로컬 라우터, 입력 쿼리 분류기, 의도 파악(Intent Classification), 실시간 텍스트 정제 및 요약 시스템의 전처리 백엔드로 활발히 기여하고 있습니다. 낮은 메모리 점유율 덕분에 서버 비용을 극단적으로 줄이면서 대규모 분산 엣지 환경에 즉시 배치할 수 있다는 장점이 있습니다.

## 한계
5억 개의 매개변수를 지닌 극소형 모델의 물리적 특성상, 7B 이상의 중대형 모델이나 72B 플래그십 모델에 비해 다단계 논리 추론, 고난도 수학 증명, 상복합 코딩 작성 시 오류율이 상대적으로 높습니다. 또한 복잡하고 긴 지시사항이 다중으로 부여될 때 지시 정렬(Instruction Following)이 미흡해질 수 있으며, 이미지·음성 처리를 위한 바이패스 모듈이 내장되지 않은 순수 텍스트 전문 모델입니다.
