# Yi-1.5-34B-Chat 소개

## 개요
Yi-1.5-34B-Chat은 글로벌 혁신 AI 기업인 01.AI(零一万物)가 2024년 5월에 정식으로 출시한 고성능 대형 언어 모델입니다. 이 모델은 이전에 큰 주목을 받았던 Yi-1.0 모델을 기초 체력과 정렬(Alignment) 면에서 전면적으로 한 단계 업그레이드한 340억(34B) 파라미터 크기의 대화 최적화(Chat) 모델입니다. 적당한 규모의 로컬 배포 혹은 고성능 클라우드 호스팅에 가장 이상적인 34B 사이즈로 최적화되었음에도 불구하고, 최신 정밀 파이프라인과 대규모 학습 정제 데이터를 바탕으로 설계되어 동급 오픈소스 진영 중 압도적인 상식 추론과 논리력, 그리고 긴 대화 정밀도를 갖추었습니다.

## 기술 특징
Yi-1.5-34B-Chat은 베이스 모델 학습 과정에서 5천억(500B) 개의 엄선된 고품질 토큰을 추가로 적용하여 코딩 성능, 기계 학습 상식, 수학적 다단계 연산 능력을 극대화했습니다. 32,000 토큰(32K)에 달하는 넉넉한 입력 컨텍스트 윈도우(Context Window)를 완벽하게 수용하도록 주의 기계 학습 메커니즘을 업그레이드하였으며, 이를 통해 대용량 텍스트 이해 및 긴 호흡의 사용자 지시 수집을 매끄럽게 처리합니다. 또한 정렬(Alignment) 조율 단계에서는 지도 미세 조정(SFT, Supervised Fine-Tuning)과 직접 선호도 최적화(DPO, Direct Preference Optimization) 공정을 결합한 진보된 하이브리드 강화 학습 아키텍처를 도입하여 복잡한 인간의 대화 뉘앙스를 탁월하게 추종합니다.

## 사용 사례
Yi-1.5-34B-Chat은 단일 고사양 GPU나 다중 GPU 시스템을 구축한 사내 엔터프라이즈 환경에서 지능형 AI 에이전트를 운영하는 데 최고의 활용도를 보여줍니다. 대용량 문서 및 사내 문서를 다방면으로 탐색해야 하는 지식 베이스 검색 증강 생성(RAG) 파이프라인에서 긴 컨텍스트 지원 능력을 십분 발휘하여 정밀한 요약 및 데이터 통합 작업을 지원합니다. 아울러 대폭 개선된 소프트웨어 개발 도우미 성능을 활용하여, 고난도의 다중 파일 코드 파싱, 복잡한 파이썬 스크립트 작성, 알고리즘 최적화 디버깅 솔루션 등의 첨단 개발 에이전트로 다양하게 전개될 수 있습니다. 범용 라이선스인 아파치 2.0(Apache-2.0) 규정하에 릴리스되어 영리 기업이나 개인 연구자 모두 제약 없이 프로덕션 서비스에 활용할 수 있습니다.

## 한계
340억 개의 매개변수 규모로 경량 고효율 구조를 정립했으나, 수천억 개 단위 이상의 초거대 클라우드 기반 LLM이나 프라이빗 클라우드 엔진들과 비교할 때는 전반적인 지식의 밀도와 복합 학문적 뉘앙스 처리에서 한계를 보일 수 있습니다. 또한 고해상도 그래픽 비전 인식, 오디오 데이터 실시간 처리 등 멀티모달 상호작용이 전혀 고려되지 않은 오직 텍스트 생성 전용 모델로 설계되어 다차원 신호 처리는 불가능합니다. 뛰어난 성능만큼 6B나 9B급 소형 모델 대비 다소 높은 VRAM 용량과 메모리 전송 대역폭을 요구하므로 모바일 기기나 저성능 단일 에지 보드에서 직접 가동하기에는 현실적인 하드웨어 장벽이 따릅니다.
