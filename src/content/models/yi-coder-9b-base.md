# Yi-Coder-9B 소개

## 개요
Yi-Coder-9B(Base)는 글로벌 AI 기업 01.AI(零一万物)가 2024년 9월에 공식 공개한 코드 생성 및 소프트웨어 엔지니어링 특화 사전 학습(Base / Pre-trained) 대형 언어 모델입니다. 8.9B(약 89억) 개의 매개변수를 기반으로 구축되었으며, 10B 이하 경량 체급임에도 불구하고 우수한 언어 모델링 성과와 깊이 있는 소스 코드 이해 능력을 제공합니다.

오픈소스 Apache 2.0 라이선스로 배포되어 연구자, 개인 개발자 및 기업 개발팀이 상업적 제한 없이 자체 인스트럭션 튜닝, 도메인 파인튜닝, 코드 인필링(FIM) 연구 및 사내 보안 온프레미스 플랫폼 구축에 자유롭게 활용할 수 있습니다.

## 기술 특징
Yi-Coder-9B는 Python, C++, Java, JavaScript, TypeScript, Go, Rust, SQL, HTML/CSS 등 52개 이상의 다양한 프로그래밍 언어 코퍼스를 집중적으로 정제하여 학습에 반영하였습니다. 특히 소형 베이스 모델임에도 불구하고 기본적으로 최대 128,000 토큰(128K)의 초장문 컨텍스트 창을 안정적으로 지원하여 수십 개의 파일로 이루어진 프로젝트 전체 코드베이스나 대용량 기술 문서를 한 번에 입력받아 전역 맥락 및 모듈 간 의존성을 정밀하게 파악할 수 있습니다.

지시 이행(Instruct) 단계를 거치기 전의 순수 사전 학습 모델로서, 코드 완성(Code Completion), FIM(Fill-in-the-Middle) 보완 및 전용 코딩 지능 개발을 위한 강력한 가중치 기반 파운데이션 역할을 수행합니다.

## 사용 사례
Yi-Coder-9B는 개발자 IDE 내장형 실시간 코드 자동 완성 엔진, 로컬 소스코드 완성 스크립트, 레거시 코드 리팩토링 및 도메인 전용 코딩 보조 도구를 구축하기 위한 시작점 모델로 적합합니다. 128K 컨텍스트 창을 활용해 대규모 프로젝트의 코드 의존성 지도 생성 및 자동 문서화 사전 처리 작업에도 유용하게 활용할 수 있습니다.

또한 사내 프라이빗 소스코드 유출을 방지해야 하는 기업 온프레미스 환경에서 전용 개발 지침이나 인하우스 프로그래밍 언어 표준을 학습시키기 위한 기본 베이스 모델로 적극 채택됩니다.

## 한계
이 모델은 대화형 얼라인먼트나 SFT(Supervised Fine-Tuning) 조정을 거치지 않은 순수 사전 학습 베이스 모델입니다. 따라서 대화형 질문이나 지시문에 직접 응답하기보다는 입력된 코드/텍스트를 이어서 작성하는 생성을 수행합니다. 지용자 친화적인 챗봇 형태나 지시 이행 도구로 가동하기 위해서는 Yi-Coder-9B-Instruct와 같은 지시어 튜닝 모델을 사용하거나 추가적인 Fine-tuning 공정이 요구됩니다.
