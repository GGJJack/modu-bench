# Yi-Coder-1.5B 소개

## 개요
Yi-Coder-1.5B는 01.AI에서 2024년 9월에 공개한 초경량 코드 특화 사전 학습(Base / Pre-trained) 대형 언어 모델이다. 단 1.5B(15억) 개 매개변수 규모의 매우 효율적인 네트워크 구조를 가지며, 소형 파라미터 체급임에도 우수한 코드 이해 및 언어 모델링 성능을 제공하도록 설계되었다.

Apache 2.0 오픈소스 라이선스로 제공되어 개인 연구자 및 기업 개발자가 자유롭게 자체 인스트럭션 튜닝, 파인튜닝, 연구 개발 및 온프레미스 시스템 구축에 이용할 수 있다. 소형 모델로는 이례적으로 최대 128K 토큰의 긴 컨텍스트 창을 내장하여 대용량 소스코드 파일이나 멀티 파일 기반 분석 작업을 무리 없이 수행한다.

## 기술 특징
Yi-Coder-1.5B는 Java, Python, JavaScript, C++, Go, Rust, SQL 등 총 52개에 달하는 다양한 프로그래밍 언어 데이터셋을 엄선하여 사전 학습되었다. 1.5B 파라미터 규모에 최적화된 학습 파이프라인을 적용하여 추론 시 연산 메모리 요구량을 크게 줄였으며, Hugging Face Transformers, vLLM, Ollama, SGLang 등 주요 추론 및 학습 프레임워크와의 완벽한 호환성을 제공한다.

지시 이행(Instruction/Chat) 미세조정을 거치기 전의 순수 사전 학습 모델로서, 코드 완성(Code Completion), 인필링(Fill-in-the-Middle, FIM) 및 도메인 특화 데이터 기반 파인튜닝을 위한 고품질 베이스 파운데이션 역할을 충실히 수행한다.

## 사용 사례
Yi-Coder-1.5B는 메모리와 연산 자원이 한정된 에지 디바이스, 개인 개발자 노트북, IDE 플러그인 등 온디바이스(On-device) 환경에서 코드 자동 완성 엔진의 베이스 모델로 활용하기에 최적이다. 적은 메모리 사용량 덕분에 로컬 환경에서도 지연 시간이 매우 짧은 코드 제안 기능을 구현할 수 있다.

또한 특정 기업 내부 코드베이스 및 전용 프로그래밍 언어/프레임워크에 특화된 맞춤형 코딩 도우미 모델을 구축하려는 개발팀에게 우수한 연속 학습 및 미세조정(Fine-tuning) 출발점을 제공한다.

## 한계
이 모델은 지도 학습 미세조정(SFT)이나 대화형 얼라인먼트가 적용되지 않은 순수 베이스 사전 학습 모델이다. 따라서 자연어 사용자의 직접적인 질의응답이나 대화형 대화 요청에 대해 정제된 답변을 생성하지 않고, 입력된 텍스트/코드를 계속해서 이어 작성하는 생성 특성을 보인다. 대화형 인터페이스로 가동하려면 Yi-Coder-1.5B-Chat 과 같은 인스트럭션 튜닝 모델을 사용하거나 추가 튜닝 공정이 필요하다.
