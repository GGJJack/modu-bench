# LLM-jp-3 70B 소개

## 개요
LLM-jp-3 70B는 일본 국립정보학연구소(National Institute of Informatics, NII) 대규모 언어모델 연구개발센터가 이끄는 산학연 통합 연구 컨소시엄 'LLM-jp'에서 개발하여 2024년 10월 23일 정식 공개한 700억 파라미터(70B) 규격의 일본어 사전 학습(Pre-trained) 기저(Base) 언어 모델입니다. LLM-jp 3세대 시리즈(1.8B, 3.7B, 13B, 70B) 중 가장 뛰어난 어휘 표상력과 복잡 문맥 추론 능력을 갖춘 플래그십 모델로, 일본 자국 기술 기반의 오픈소스 AI 주권 확보 및 소버린 AI(Sovereign AI) 가치 구현을 주요 목표로 제작되었습니다. 완전한 투명성과 학술적·산업적 오픈 커뮤니티 기여 정책에 입각하여 Apache License Version 2.0으로 가중치가 배포되었습니다.

## 기술 특징
LLM-jp-3 70B는 Wikipedia, Common Crawl, Kaken 연구 데이터, WARP PDF/HTML 수집 코퍼스 등을 엄격히 정제한 총 2.1조(2.1 Trillion) 토큰 규모의 'llm-jp-corpus-v3'를 기반으로 사전 학습되었습니다. 일본어 분절 효율과 단어 당 정보 밀도를 극대화한 독자 토크나이저 'llm-jp-tokenizer v3.0'을 적용하고 있으며, 기본 4,096 토큰의 컨텍스트 윈도우를 제공합니다. 특정 대화 양식이나 지시 정렬이 이루어지지 않은 완결형 사전 학습 가중치 상태로서, 700억 파라미터의 풍부한 신경망 용량을 바탕으로 복잡한 일본어 문법, 상식 추론, 전문 도메인 어휘 이해에서 뛰어난 기저 언어 성능을 보여줍니다.

## 사용 사례
LLM-jp-3 70B는 인스트럭션 튜닝이나 인간 피드백 기반 정렬(RLHF/DPO) 이전에 위치한 순수한 파운데이션 모델이므로, 고난도 독자 비즈니스 데이터를 활용해 기업 전용 맞춤형 지시 모델(Instruct model)이나 전문 도메인 챗봇을 자체 구축하려는 개발팀에 최고의 베이스라인 가중치를 제공합니다. 특히 독자 데이터셋을 투입한 LoRA/QLoRA 미세조정(Fine-tuning), 법률·금융·의료 특화 지식 파이프라인 학습, 다국어 코퍼스 가공용 사전 언어 모델, RAG(검색 증강 생성) 시스템의 임베딩 및 문맥 평가 교사 모델(Teacher Model)로 활발히 활용됩니다. Apache-2.0 라이선스 규정에 따라 상업적 제품 제작 및 가중치 수정 배포 시 추가적인 승인 절차가 필요하지 않은 장점이 있습니다.

## 한계
본 모델은 대화 포맷이나 지시 정렬 처리가 포함되지 않은 기저(Base) 사전 학습 가중치이므로, 단순 프롬프트 입력 시 사용자의 질문에 직접 응답하기보다는 문장의 후속 텍스트를 연이어 생성하는 자동 완성(Text completion) 특성을 나타내므로 직접적인 대화형 AI 서비스에 투입하기 위해서는 사전 지시어 미세조정이 필수적으로 수반되어야 합니다. 또한 이미지나 오디오 신호를 수용하는 비전·음성 모듈이 배제된 순수 텍스트 언어 모델에 해당하며, 4,096 토큰 수준의 컨텍스트 길이 제약으로 초장문 문서의 일괄 입력 처리에는 한계가 존재합니다. 아울러 70B급의 초대형 신경망 체급으로 인해 원활한 추론을 위해서는 다중 GPU 병렬 처리 인프라 구축이 선행되어야 합니다.
