# TinySolar-187m-4k 소개

## 개요
TinySolar-187m-4k는 국내 대표 AI 기업 업스테이지(Upstage)가 개발 및 공개한 약 1억 8700만(0.2B) 파라미터 매개변수 규모의 초경량 언어 모델(SLM)입니다. 업스테이지의 대표 플래그십 모델인 Solar 시리즈의 정교한 가중치 경량화 기법과 압축 학습 노하우를 계승하여 탄생했습니다. 클라우드 API 호출이나 고성능 서버용 GPU 장비 없이도 사용자 디바이스, 임베디드 단말, 소형 모바일 디바이스 등 리소스가 지극히 제한된 엣지 컴퓨팅 환경에서 매우 빠른 텍스트 처리 성능을 발휘합니다.

## 기술 특징
TinySolar-187m-4k의 독자적인 아키텍처는 초소형 크기임에도 불구하고 4096 토큰(4K)에 이르는 시퀀스 길이를 효율적으로 지탱할 수 있도록 가중치가 최적화되어 있습니다. 초경량 구조 덕분에 메모리 풋프린트(Memory Footprint)가 현저히 적어 디바이스 내 NPU, 소형 모바일 GPU, 인텔/ARM CPU 단독 환경에서도 수 밀리초(ms) 단위의 빠르게 시작되는 초저지연 추론이 가능합니다. 또한 Apache-2.0 오픈소스 라이선스가 적용되어 온디바이스 파이프라인 탑재 및 특정 도메인 맞춤형 미세조정(Fine-Tuning) 연구가 자유롭습니다.

## 사용 사례
이 모델은 온디바이스 오프라인 환경에서 실시간 텍스트 교정, 자동 완성, 키워드 추출, 소형 요약 파이프라인을 구축하는 데 매우 강력한 위력을 발휘합니다. 사물인터넷(IoT) 기기 및 스마트 가전 제어반, 모바일 가상 키보드 예측, 온디바이스 로컬 키워드 필터링 등 높은 응답 속도와 완벽한 데이터 보안이 요구되는 영역에 적합합니다. 아울러 특정 업무 도메인의 소형 데이터셋으로 정밀 파인튜닝하여 전용 온디바이스 분류기나 임베디드 추론 모듈로 확장하기에 용이합니다.

## 한계
1.87억 개의 파라미터만을 탑재한 초경량 모델이므로, 수백억~수천억 파라미터급 대형 모델들이 보여주는 복잡한 다단계 논리 추론, 깊이 있는 학술 전문 지식 응답, 고난도 프로그래밍 코드 작성 기능 등은 구조적으로 수행하기 어렵습니다. 또한 복잡한 도구 호출(Tool Use)이나 에이전트형 제어 기능은 공식 지원되지 않으며, 4K 토큰을 초과하는 초대형 문서 처리 시 정보 손실이 발생할 수 있습니다. 입력 및 출력 특성이 텍스트 생성 및 분류에 특화되어 있어 복합 시각 데이터나 음성 신호를 مستقیم 처리하는 능력은 갖추고 있지 않습니다.
