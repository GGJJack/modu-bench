# Command R+ 소개

## 개요
Command R+는 2024년 4월 4일 코히어(Cohere)와 코히어 랩스(Cohere Labs)가 공개한 1,040억(104B) 파라미터 규모의 플래그십 오픈 웨이트 대규모 언어 모델입니다. 기업들이 PoC(개념 검증)를 넘어 복잡하고 미션 크리티컬한 엔터프라이즈 환경을 프로덕션으로 전환할 수 있도록 최고 수준의 성능과 정확도를 제공합니다.

Command R의 확장 모델인 Command R+는 정교한 검색 증강 생성(RAG)과 여러 도구를 순차적으로 연계해 복합 문제를 해결하는 다단계 도구 사용(Multi-Step Tool Use/Agents)에 특화되어 있으며, 10개 핵심 비즈니스 언어에서 프런티어급 추론 역량을 발휘합니다.

## 기술 특징
Command R+는 104B 파라미터의 최적화된 트랜스포머 아키텍처를 채택하였으며, 엄격한 지도 미세조정(SFT)과 선호도 학습을 통해 비즈니스 유용성과 안전성을 극대화했습니다.

주요 기술적 성과는 다음과 같습니다:
- **다단계 도구 사용(Multi-Step Tool Use / Agents)**: 단일 호출에 머무르지 않고, 복잡한 사용자 요청을 해결하기 위해 '행동(Action) → 관찰(Observation) → 반추(Reflection)'의 추론 루프를 반복 수행하며 여러 도구를 유기적으로 연쇄 호출할 수 있는 에이전트 역량을 갖추었습니다.
- **근거 기반 생성(Grounded Generation) 및 인용**: 긴 문서 뭉치나 검색 결과에서 핵심 근거를 식별하고, 답변의 각 주장이 어떤 출처 스니펫에 기반했는지를 명시적 인용 스팬(`<co: doc>`)으로 연결하여 환각을 억제합니다. 정확도를 우선하는 accurate 모드와 토큰 소모를 줄이는 fast citation 모드를 모두 지원합니다.
- **128k 긴 컨텍스트 윈도우**: 128,000 토큰에 달하는 대용량 컨텍스트를 지원하여 방대한 계약서, 규정 문서, 대화 히스토리를 한 번에 입력받아 다차원적 분석을 수행할 수 있습니다.
- **다국어 추론**: 한국어, 영어, 프랑스어, 스페인어, 독일어, 이탈리아어, 일본어, 중국어(간체), 브라질 포르투갈어, 아랍어 등 10개 언어에서 고난도 추론과 교차 언어 질의응답 및 번역을 원활하게 수행합니다.
- **오픈 LLM 리더보드 벤치마크**: 공개 당시 Hugging Face Open LLM 리더보드에서 평균 74.6점을 기록하며 DBRX Instruct(74.5)와 Mixtral 8x7B Instruct(72.7), Llama 2 70B(67.9) 등을 상회하는 오픈 웨이트 최고 수준의 성능을 입증했습니다.

## 사용 사례
Command R+는 다단계 금융 분석 에이전트, 기업 전사적 자원 관리(ERP) 및 고객 관계 관리(CRM) 연동 비서, 복합 법률 및 규제 문서 감사, 고난도 고객 상담 오케스트레이션 등 최고 난도의 비즈니스 워크플로우에 최적입니다. 또한 공식 API를 통해 1M 토큰당 입력 $3.00, 출력 $15.00(08-2024 버전의 경우 입력 $2.50, 출력 $10.00) 수준으로 동급 프런티어 독점 모델 대비 경쟁력 있는 비용으로 엔터프라이즈 환경에 배포할 수 있습니다.

## 한계
Command R+는 순수 텍스트 언어 모델로 멀티모달(비전, 음성) 입력은 지원하지 않습니다. 104B에 달하는 파라미터 크기로 인해 온프레미스 직접 구동 시 최소 80GB 이상의 고사양 GPU 클러스터나 양자화(4-bit/8-bit bitsandbytes 등) 환경이 요구됩니다. 또한 오픈 가중치는 CC-BY-NC-4.0 라이선스로 연구 및 비상업적 용도로 제공되므로, 기업에서 독자적으로 온프레미스 상업 배포를 하고자 할 때는 코히어와의 상용 라이선스 협의가 필요합니다.
