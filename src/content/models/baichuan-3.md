# Baichuan 3 소개

## 개요
Baichuan 3는 백천지능(Baichuan Intelligent Technology)이 2024년 1월 발표한 3세대 대형 언어 모델(LLM)입니다. 이전 세대인 Baichuan 2의 오픈소스 성과와 인프라 노하우를 바탕으로, 수천억 파라미터급 대규모 데이터와 고도화된 아키텍처 개선을 적용하여 개발되었습니다. 특히 중국어 문맥 이해와 다국어 문제 해결 능력, 고난도 추론 능력에서 글로벌 선도급 성능을 보유하고 있습니다.

## 기술 특징
Baichuan 3는 대규모 합성 데이터 증강 기법과 엄선된 고품질 토큰 코퍼스를 활용하여 학습되었습니다. 모델의 인코딩 정밀도와 토큰화 효율이 대폭 개선되어, 수학적 논리 추론, 프로그래밍 코드 생성, 의료 및 법률 전문 지식 질의응답 등의 평가 영역에서 우수한 성적을 나타냅니다. 또한 백천지능 독자의 정렬(Alignment) 기술을 접목하여 안전하면서도 사용자 프롬프트 의도에 정밀하게 부합하는 응답을 제공합니다.

## 사용 사례
Baichuan 3는 대규모 기업용 검색 증강 생성(RAG) 시스템, 에이전트 기반 작업 자동화, 전문 분야 문서 분석 및 보고서 작성 등에 폭넓게 활용됩니다. 백천지능의 클라우드 API 및 엔터프라이즈 솔루션과 연동되어 금융, 의료, 마케팅 등 고도의 도메인 지식이 요구되는 산업군에서 정확도 높은 인공지능 기반 서비스를 구축하는 데 쓰입니다.

## 한계
Baichuan 3는 백천지능의 초대형 플래그십 모델로서 클라우드 API 형태로 주로 상용화되어 있어, 가중치가 전면 공개된 오픈소스 모델들과 달리 개별 사용자의 온프레미스 가중치 수정이나 경량 로컬 배포에는 제약이 따릅니다. 또한 순수 텍스트 언어 모델로 설계되어 음성이나 이미지 등 다중 모달리티(Multimodal) 입력을 직접 수용하지는 못합니다.
