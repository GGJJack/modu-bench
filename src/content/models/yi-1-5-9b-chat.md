# Yi-1.5-9B-Chat 소개

## 개요
Yi-1.5-9B-Chat은 혁신적인 인공지능 스타트업인 01.AI(零一万物)가 2024년 5월에 정식 론칭한 차세대 경량급 고성능 대화 모델입니다. 이 모델은 기존 오픈소스 진영에서 최고의 성능 지표를 보여주며 각광받았던 Yi-1.0 모델 아키텍처를 계승 및 보완하여, 실용성과 에너지 효율성을 극대화한 90억 파라미터(9B) 규모로 새롭게 탄생했습니다. 정밀한 대화 형식 정렬(Alignment) 기법이 완성도 높게 적용되어 일상적인 질의응답은 물론 복잡한 문맥 해석과 유저 지시어 준수 능력이 괄목할 수준으로 향상되었으며, 글로벌 개발자들에게도 뛰어난 언어 유연성과 탄탄한 다국어 상호작용 속도를 제공합니다.

## 기술 특징
Yi-1.5-9B-Chat은 기본 뼈대가 되는 베이스 모델 학습에 총 5천억(500B) 개의 엄선된 고품질 토큰을 추가로 공급하여 수학적 논리 추론, 복잡한 상식 검증, 고성능 코딩 역량을 대폭 업그레이드했습니다. 정렬 단계에서는 지도 미세 조정(SFT)과 직접 선호도 최적화(DPO, Direct Preference Optimization)를 이상적으로 연동한 하이브리드 최적화 기법을 도입하여, AI 모델이 출력하는 답변의 품질을 사용자 맞춤형 선호도에 어울리도록 조율해 냈습니다. 또한, 뛰어난 경량 아키텍처 설계를 활용해 적은 자원으로도 우수한 메모리 대역폭 성능과 가중치 전송 이점을 지녀 일반적인 GPU 기반 디바이스 상에서도 지연 속도가 극단적으로 제어된 실시간 응답 환경을 조성합니다.

## 사용 사례
Yi-1.5-9B-Chat은 리소스가 제한적인 온디바이스(On-device) 또는 단일 GPU 탑재 서버 기반 챗봇 구축 시나리오에 최고의 선택지 중 하나로 꼽힙니다. 복잡한 명령어가 얽혀 있는 웹 서비스용 가상 도우미, 고속 텍스트 생성 파이프라인, 모바일 메신저 서비스 내의 경량 번역기 등으로 다각도로 구현될 수 있습니다. 특히 향상된 소스 코드 생성 및 파싱 능력을 살려 로컬 소프트웨어 빌드 환경에서의 가벼운 실시간 코드 완성 에이전트, 개발 테스트용 스크립트 작성 보조 장치 등 고도의 테크니컬 어시스턴트로 다채롭게 전개하는 것이 가능합니다. 아파치 2.0(Apache-2.0)이라는 폭넓은 범용 오픈 라이선스로 릴리스되어 상업 및 연구 목적의 전방위 결합에서도 아무런 제약 없이 쓰일 수 있습니다.

## 한계
이 모델은 90억 파라미터 크기 수준에 맞춰 최적화된 경량 세대 모델인 만큼, 수천억 개 단위의 최고 스펙 프라이빗 클라우드 LLM들이 가지는 심도 깊은 추상적 다단계 논증 연산에서는 다소 밀리는 모습을 볼 수 있습니다. 메타데이터에 각인된 최대 입력 컨텍스트 윈도우 한계가 기본적으로 4K(4096 토큰) 스펙에 묶여 있기 때문에, 방대한 크기의 기업 보고서나 소스 코드 전체 모듈을 통째로 넘겨받아 면밀한 다중 파일 RAG(검색증강생성)를 구사하는 분야에는 다소 한계가 존재합니다. 또한 완전한 텍스트 변환 처리를 지향하는 가중치 훈련 공정을 밟은 소형 모델이므로 물리적 전경 이미지나 복합 동영상, 원천 음향 파일 등 외부 비주얼 및 멀티모달 요소들을 한 호흡에 입력받고 다차원 분석을 끌어내는 것 역시 직접적으로는 지원하지 않습니다.
