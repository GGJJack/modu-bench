# Northeastern University Programming Research Lab

Northeastern University Programming Research Lab (NUPRL)은 Northeastern 대학의 프로그래밍 연구소입니다.

이 연구소는 대규모 언어 모델이 어떻게 여러 프로그래밍 언어의 생성을 일반화할 수 있는지 탐구하기 위한 벤치마크 시스템인 MultiPL-E를 공개했습니다.

MultiPL-E는 단위 테스트 주도형 코드 생성 벤치마크를 새로운 프로그래밍 언어로 번역하는 확장 가능하고 확장성 있는 방식을 제안하여 새로운 모델, 벤치마크, 프로그래밍 언어를 유연하게 평가할 수 있도록 합니다.
